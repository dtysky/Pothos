# 坦克500村道事故 Vlog

记录瞬光的坦克500在阳春村道发生事故后，从同责认定、定损、联系对方、准备代位追偿到一次性结案和车辆修复的过程。

## 当前阶段

口播稿已确认，待录制家中口播并整理现有视频、录音进入剪辑。现有原始媒体尚未导入本项目，当前稿件依据用户提供的事实文档和对话补充编写。

## 文件入口

- [家中口播拍摄稿](scripts/voiceover.md)：十三段独立口播，按最新确认的自然聊天语气编写。
- [剪辑脚本](scripts/editing.md)：各段口播与现有素材的衔接顺序。
- [事故事实来源](notes/accident-facts.md)：用户提供的原始文字记录。
- [制作共识](notes/production-decisions.md)：已确认的开场、语气、时间表达、素材和事实补充。

## 后续工作

按口播稿分段录制；整理现场、行车记录仪、电话和门店视频；对照实际媒体确认选段与慢放位置，再按剪辑脚本串联。
