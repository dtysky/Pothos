### 基本信息

- **代号**：ProjectRoot
- **输出形态**：纪录片

### 核心主题

一个在中国土生土长却一直漂泊、没有故乡的人，从现在所在的地方出发，穿越大半个中国，回到出生的地方。

核心命题是"落叶归根"的悖论：文化承诺你有根可回，但如果你从来没在那里扎下过，那个地方到底是不是你的根？

## ProjectTomorrow

### 核心主题

`ProjectTomorrow` 更像一场追索式悼亡叙事：

- 一个并非天然想死的人
- 如何被家庭结构、性别规训、精神困境、社会误读与错失的求救
- 一步步推向死亡

### 关键关系

- 戴无垠与项君歌：镜像关系 + 不对称关系
- 她把他当作理想、出口与彼岸
- 他在她死后才被迫成为见证者、理解者与迟来的拯救者
- 施云承担现实桥梁功能
- 女主父母承担伤害结构与世俗误读

### 叙事方式

其结构偏好非常清晰：

- 现实追索
- 葬礼 / 调查
- 日记回溯
- 超现实对话
- 假设推演
- 黎明判决

语气上兼有压抑、哀悼、哲思与愤怒。它不是轻盈抚慰，而是为死者争取一次温柔的无罪审判。

- 工作团队的数量关系是“我 + 四名下属”；人物设计需要逐人体现发型、脸型、眼镜、体型、笑容和姿态差异，不能做成“我的换皮”。当前人设从左到右固定为：1=我、2=组员丁、3=组员乙、4=组员丙、5=组员甲；身高依次为 175、171、173、177、178 cm，五人都偏瘦，组员丙与组员甲体型基本一致；组员乙穿浅色短袖、黑色短裤、黑色斜挎包和白鞋。
- 工作空间包括现代玻璃建筑园区、开放式工位和独立的公司地库；家中地库与公司地库必须作为两个地点处理。
- 深圳最终竞聘后的谈话发生在大型阶梯会议室：会议结束后整间空间只剩我与男性 HR，两人并排坐在最前排正中间；不能改成会议桌对谈、普通小会议室或多人评审席。

### 参考素材使用边界

- 实景图用于锁定空间、比例、材质、光线和动作，不直接替代统一画风下的最终镜头。
- 地点母版应把实景透视和空间完整重绘为高分辨率硬边像素环境，不使用近写实 CG 叠像素滤镜；人物与环境共用接近 CHAR-H 的像素密度。
- 车牌、工位屏幕、工位编号和园区路人正脸默认不进入成片；团队成员可以做低分辨率像素化特征提炼，但不做写实肖像复刻。
- 商品睡衣图只锁定款式与配色，不能代替 CHAR-H 的体型与穿着参考。

### CG 资产工作流

- 所有新生成 CG 的原始输出、修改稿和候选版本统一放入已被 Git 忽略的 `art/generated/SHOT-xx/`。
- 审核前不把生成稿复制到受 Git 管理的第二个目录；审核通过后，只向 `game/assets/shots/shot-xx/` 导出一份游戏实际加载的最终资产。
- `art/` 只保留规范、台账和生成记录，不再另存最终 CG；同一画面也不得在运行时镜头包内以 `master`、`base`、`variant` 等不同文件名重复保存。
- 对包含多段现实复现的章节，先为每个事实节点建立独立母帧和机位；即使地点相同，也不能只换屏幕内容冒充新场景。
- 生产顺序固定为：ignored 目录中的唯一候选通过初审 → 导出一张 4K 运行时母帧 → 带真实台词实机审查 → 只补确有叙事价值的差分和有限动画。不要在母帧阶段提前批量制造 `variant`。
- 非 16:9 候选进入运行时前优先居中裁切或重新构图，禁止横向拉伸人物比例；裁切是否成立必须在真实字幕布局下复核。

### 游戏声音演出的固定方法

- 用户已确认旁白“人声美化”采用 B 方案，并固定为 Godot 实时处理而非离线重编码：所有当前非 soundtrack 的主角旁白进入独立 `Narration` 总线，使用 65 Hz 高通、轻度身体感／存在感 EQ、温和压缩、约 1.8 dB 补偿和限幅；8 kHz 轻衰减近似克制的齿音控制。G4-01 的旧作混合原声必须继续走无效果的 `Voice` 总线；环境声、Foley 与未来非主角语音不得误入 `Narration`。
- G0 现实通勤段的 `G1-01-21`“我不明白”已按用户要求恢复：它在“本应如此，但是——”后独立切黑并播放，下一句“是啊……”再进入公司地库。梦境开场原先重复的同句仍不恢复；后续重建剧本或重切母音频时不得再次把两处混为一谈。
- 2026-08-17 使用 Kairos 更新后的 `me-sad` 生成的 G0 六段候选试听包暂时搁置，尚未进入运行时；这一决定与现有演出的字幕错位是两件独立的事，不能把错位归因于新版音色。
- 现有运行时配音已确认存在多处分页边界错位，原因是旧流程先把多句合成为母音频，再以静音检测和字数估算自动切页；句内逗号停顿会被误认成页面边界，使上一页后半句移到下一页开头。后续修复必须按受影响页面单独生成或使用可靠的文本时间戳切分，并在接入前逐页做 ASR 对照，不能继续只靠静音检测。
- 2026-08-18 已建立独立 `SoundDirector`，首批由用户提供的九段组合母带切分接入：G0 开场风啸、教堂钟声、列车汽笛与后续天台风，G1 洗漱、车门、通勤车内／城市环境和办公室环境，以及 G5 夜间灯塔至最终空镜的海风海水。开场风啸先独立建立空间，后续天台风再接入并可在 `G1-04` 山地创作表演复用；办公室声只覆盖 `G1-03` 工位，不覆盖 `G1-02` 园区散步。持续环境使用双播放器淡化并制作循环接缝；一次性事件拥有明确的镜头有效范围，离开范围即短淡出，不能跨场残留。钟声与汽笛属于锁定式前置演出：分别在 `G1-01-D03`、`G1-01-D17` 完整播放后才切入结果画面和反应台词。通勤环境在 `G1-01-21` 黑场前快速抽离，终幕海声从 `G5-04-03` 灯塔出现起持续到 `MUS-09C` 退出后。读档只恢复当前环境，不重放当前行的一次性动作。
- 章节或音乐段落切换时，旧音频必须在画面切换前完成渐隐；新画面揭示的同一时刻启动新 BGM，不再让新画面先裸露后延迟进音乐。
- 全剧声音由四层组成：持续的空间底噪 `Ambience Bed`、可按镜头切换的活动层 `Activity Stem`、稀疏且有叙事动作依据的 `Foley／Event`，以及随画面内外、远近和回忆状态变化的 `Perspective`。声音跟随场景和画面状态，不跟随每一次翻页；玩家控制阅读节奏时禁止添加固定翻页声。
- 情绪主要通过声音的连续、抽离、远近与材质变化表达，不使用电影预告式低频撞击、游戏化 UI 呼啸、心跳、AI 数字闪烁、魔法提示音、成功音效或罐头笑声。G3 的 Agents 由各自真实工作空间成立，而不是靠“科技感”音效成立。
- G1 回放段固定在 BGM 渐隐后使用两至三个极短、可辨认的场内声音倒放碎片，随后收窄到近距离呼吸与房间底噪；G4-01 的旧作混合原声不叠加新音效，G4—G5 的旅行段必须保留真实地理与天气差异，最终无人灯塔在音乐退出后只留下海声，不加通关或抒情收束提示。
- 详细的 28 个演出单元 Cue 表、复用资产表、制作优先级与验收标准见 `projects/project-birthday-33/design/sound-effects-design-20260817.md`。

### 游戏配乐的固定方法

- 2026-08-16 已确认 G0—G3 配乐整体重制：最终只保留 G0、G1、G2、G3 各一首常驻 BGM，G3 十秒检索另用一首事件曲，共五个音乐资产；检索结束后回到同一首 G3 主曲，不再拆出“辨认／信念／开始”等额外曲目。五首是最终运行时数量，但候选数量不再机械固定为 A／B；低余额时优先单 Variant、短时长和分段验收。
- 2026-08-16 第一次五首重制试生成确认“常规独立叙事游戏／视觉小说 BGM”同样不符合整体气质；视觉小说只是交互形式，不能再作为音乐类型锚点。该版温暖、规整、轻巧、功能化的提示词已作废。

## 共有创作倾向

- 把私人经验写成一代人的精神症候
- 强烈关注审判与无罪
- 偏爱镜像人物、投射关系、替身结构
- 高频使用意义、自由、信念、和解、虚无、审判、渴望等高密度概念词
- 常在现实创伤上叠加超现实或舞台化装置
- 结尾偏向继续活下去，但拒绝虚假圆满

## 可复用的叙事规则

### 1. 抽象命题先落场景

先给抽象命题一个具体情境，再让人物说出观点。不要直接让概念彼此碰撞。

### 2. 关系尽量错位

比起平直互诉，更有效的是：

- 爱与理解不对称
- 看见与被看见错位
- 求救与接收错位
- 拯救与迟到错位

### 3. 社会批判要落在结构节点

更适合承载冲突的现实节点：

- 家庭
- 学校
- 职场
- 医疗
- 婚恋市场
- 同辈舆论
- 公共空间

### 4. 超现实元素只做放大器

幽灵、蝴蝶、海边、黎明、镜子、舞台等装置，不需要解释过度。它们的职责是放大情感真实，而不是变成世界观负担。

### 5. 结尾不写彻底和解

更匹配的落点通常是：

- 背负着继续
- 理解了，但不轻松
- 看清了，也还得走

### 6. 人物不能只当符号

尤其写女性困境、亲密关系或家庭压迫时，要保留角色自己的判断、犹豫、抵抗和选择，避免让人物沦为观念或控诉的容器。
